# clean-code-review

Proyecto de la Semana 10 (Sesion 30) para Calidad de Software - UDLA.
Grupo: Martes_GR_ 1

## Como compilar y ejecutar

Requisitos: Java 21 y Maven.

```bash
mvn compile
java -cp target/classes SalesReview
```

## Versiones en el historial

- `v1-original`: codigo inicial proporcionado en la actividad.
- `v2-refactorizado`: codigo refactorizado aplicando principios de Clean Code junto con la configuracion de los tres plugins de Maven.
